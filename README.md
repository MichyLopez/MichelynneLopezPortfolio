# MichelynneLopezPortfolio

A responsive, multi-page portfolio starter using HTML and CSS Flexbox.

## Pages
- `index.html` — home page with a mood-board-style featured projects area
- `about.html` — biography, portrait, and creative tools
- `work.html` — four clickable work categories
- Category pages — website design, photography, graphic design, and internship work

## Preview locally
Open `index.html` in a browser. For a more reliable local preview, use VS Code's Live Server extension.

## Add your content
1. Replace `YOUR NAME` with your preferred portfolio name.
2. Add your images to the `images` folder using the filenames shown in the HTML, or update the image paths to match your own filenames.
3. Replace the sample project titles and descriptions with your real projects.
4. For video projects, you can add an embedded video or link to a hosted video. Only publish internship/client work you have permission to share.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `my-portfolio`.
2. Upload all files and the `images` folder to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. The site address will appear in the Pages settings.

Keep `index.html` in the repository root so GitHub Pages can use it as the home page.
